# CancerGuard-SVM-Cancer Detection-API

CancerGuard is an AI-powered Cancer Detection API built with FastAPI and scikit-learn, leveraging Support Vector Machine (SVM) models for accurate cancer prediction. The system supports kernel selection, hyperparameter tuning, real-time REST API inference, model retraining, and interactive Swagger UI for seamless testing and integration.
